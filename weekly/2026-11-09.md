### 1. A low-rank decoder bottleneck bounds reliability in foundation-model perturbation prediction（79/100）
- 链接：https://arxiv.org/abs/2611.05849
- 类别：可靠性 / 可解释结构分析；置信度：medium
- 分项：`{"question_shift": 20, "decision_or_experiment_shift": 17, "information_shift": 13, "evaluation_shift": 14, "evidence_strength": 11, "nontriviality": 4}`
- 新问题：基础模型扰动预测能不能给出「这一条预测可不可信」的逐条置信度，而不是只给聚合精度？可靠性的上限是否由解码器到训练响应的距离决定？
- 中文简介：把 STATE 的状态转移（ST）解码器拆开看：它在三种编码器（SE-600M、scGPT、Tahoe-x1）与四个 CRISPRi 细胞系上，第一层注意力的输出是低秩的；把该输出投影到由训练激活估计出的 4–32 个固定方向上，仍能保持逐扰动 Pearson delta 相关（PDC）的均值。由此得到一个可检验的机制性结论：这个低秩瓶颈使可靠性由「到训练响应的距离」界定——某个扰动的观测响应离最近训练响应越远（余弦距离越大），PDC 越低。基于此提出 predicted-NN-distance：预测响应到最近训练响应的余弦距离，作为逐条预测的置信分，与实际 PDC 的平均绝对 Spearman 相关为 0.81，接近用观测响应算出的 0.88；在该分数上标定的阈值可跨编码器与细胞系迁移，并且对药物扰动仍能预测 PDC。
- 证据与限制：arXiv 2026-11-06 提交（首次公开日期），预印本未经同行评审；全文未取到（仅摘要），因此低秩投影与置信分阈值的具体设定、PDC 的统计不确定度无法核实；证据限定在 STATE 系列解码器与 CRISPRi/药物扰动，尚未在其它架构上独立验证。
- 与本项目：可迁移方法
- 建议动作：把 predicted-NN-distance 接成我们扰动预测流水线的默认逐条置信度，并用它决定「哪些预测值得做湿实验」的优先级。

- 类别：数据产生 / 实验设计与评测混杂；置信度：medium
- 分项：`{"question_shift": 20, "decision_or_experiment_shift": 17, "information_shift": 12, "evaluation_shift": 14, "evidence_strength": 12, "nontriviality": 4}`
- 新问题：在多供体单细胞扰动筛选里，被当作「生物学」的差异有多少其实是板位技术效应？评测掉进的是共享对照组的技术偏移陷阱，而不是模型不够强？
- 中文简介：一篇把「数据怎么产生」纳入扰动预测评测的工作。作者指出多数多供体免疫细胞筛选采用每供体—扰动组合占一个孔、对照成组、所有供体共用同一块板布局，于是板位（well）效应会被读成生物学差异。在 90 种细胞因子筛选、两个化合物筛选、四个队列与模拟中，他们证明：在丰度高的细胞类型里，孔位效应解释了大部分重复对照之间的变异；对照孔之间携带共享偏移；在常规阈值下两个相同对照孔之间可相差数百个差异表达基因——与两种受体阴性蛋白之间的差异量级相当。更关键的是评测部分：在标准评测下得分低于「扰动无关预测器」的深度学习模型，一旦改看「扰动特异差异」分量，反而在三个细胞类型中的两个（其中一个在更严格对照下显著）优于简单基线，但它在与惰性孔共享的分量上预测更差。负对照、设计感知估计量与扰动特异评估让四篇近期分析的结论需要重新解释。

- 与本项目：直接竞争

### 4. RELAY: Relational In-Context Learning for Cellular Perturbation Prediction（73/100）
- 链接：https://www.biorxiv.org/content/10.64898/2026.10.31.763027v1
- 类别：方法 / 条件空间外推；置信度：medium
- 分项：`{"question_shift": 19, "decision_or_experiment_shift": 16, "information_shift": 12, "evaluation_shift": 12, "evidence_strength": 10, "nontriviality": 4}`
- 新问题：预测未测条件时，是否必须显式编码扰动/细胞类型/供体/剂量这些变量的数值，还是只告诉模型「哪些变量是共享的」就够？
- 中文简介：把扰动响应看成多维条件空间中的坐标（扰动身份、细胞类型、供体、剂量），现有方法依赖对这些变量值的显式表示，因此泛化到未出现的取值取决于这些表示的可得性与质量。RELAY 改走关系路线：对每个目标坐标，只输入与之共享一个或多个变量的已测「对照—扰动」配对作为演示（例如同一扰动在另一种细胞类型中的响应），并且只告诉模型哪些变量共享、不给变量值，由 in-context 推断目标响应。在化学、遗传、细胞因子三类扰动数据集上，按「未出现过的组合」与「仅通过上下文引入的未出现变量值」两种设定评测：前者优于有监督扰动预测方法，后者优于现有 in-context 方法。作者承诺开源代码与数据。
- 证据与限制：bioRxiv 2026-11-03 v1 预印本，未经同行评审；全文未取到（仅摘要 + OpenAlex 元数据），代码与数据尚未实际验证是否已发布；评测全部为保留条件回放，无前瞻实验闭环，也未给独立第三方复现。
- 与本项目：可迁移方法
- 建议动作：在我们跨细胞类型/跨供体的条件外推里加一个「仅共享关系」的 in-context 基线，检验显式变量表示是否真的必要。

### 5. CytoWave: Perturbation-Centric Pretraining for Single-Cell Response Prediction（70/100）
- 链接：https://arxiv.org/abs/2611.02311
- 类别：方法 / 预训练目标；置信度：medium
- 分项：`{"question_shift": 18, "decision_or_experiment_shift": 15, "information_shift": 12, "evaluation_shift": 12, "evidence_strength": 10, "nontriviality": 3}`
- 新问题：跨物种、跨协议的扰动响应预测，是否应该围绕「扰动」而不是「细胞」来预训练？
- 中文简介：现有扰动预测方法在不同实验协议、生物背景与物种间难以泛化。CytoWave 用同源（orthology）映射把大规模跨物种扰动数据统一，然后分两阶段训练：第一阶段在未扰动细胞上用掩码基因表达恢复学习参考对照状态；第二阶段学习在给定对照状态与扰动信号下预测扰动后表达，并加一个把扰动响应的隐表示与扰动信号对齐的对比目标。评测采用严格的数据集留出，跨多个条件组合，并给出通路活性变化的案例分析，声称在预测单细胞遗传扰动响应上稳定有效。这是一条「以扰动为中心」的预训练路线，与以细胞状态为中心的基础模型形成直接对照。
- 证据与限制：arXiv 2026-11-03 提交（首次公开日期），预印本未经同行评审；全文未取到（仅摘要，摘要中未给出任何具体指标数值），跨物种同源映射引入的偏差与留出实验的具体划分无法核实；无前瞻验证。
- 与本项目：可迁移方法
- 建议动作：作为「以扰动为中心」预训练的对照基线纳入我们的跨物种留出评测，并要求其报告逐条件而非聚合指标。

### 6. Attribution-based diagnostics for single-cell foundation models（69/100）
- 链接：https://arxiv.org/abs/2611.02335
- 类别：诊断 / 模型机制审查；置信度：medium
- 分项：`{"question_shift": 18, "decision_or_experiment_shift": 14, "information_shift": 11, "evaluation_shift": 13, "evidence_strength": 10, "nontriviality": 3}`
- 新问题：单细胞基础模型的高精度到底来自生物学信号还是模型特有的捷径——能否用事后归因把这件事查出来？
- 中文简介：提出把事后归因当诊断工具，而不是当解释装饰。在两个任务上系统检查：细胞类型注释（Cell2Sentence 与 scGPT）与扰动预测（scGPT+STATE，在受控设定下）。注释任务里用归因检查预测是否依赖已确立的 marker 基因，以及相关性如何随模型架构、表达秩与周边细胞环境变化；扰动预测任务里在合成的调控真值场景中比较归因模式与该真值，看模型实际学到了什么计算。跨任务，归因揭示了生物特征使用、上下文交互、不同输入通路的贡献、学习过程以及与预测质量的关联，也揭示了标准指标未能捕捉的陷阱。实验还表明：结论强烈依赖所选的生物学参考、基线与零模型——即便调控知识完整或受限，归因结论都会随之改变。
- 证据与限制：arXiv 2026-11-04 提交（首次公开日期），预印本未经同行评审；全文未取到（仅摘要），因此归因方法、基线/零模型的具体选择与合成真值设定无法核实；扰动预测部分为受控合成场景，不是真实数据的独立验证。
- 与本项目：可迁移方法
- 建议动作：把归因诊断（含参考/基线/零模型敏感性）加入我们对自身扰动模型的自检清单，避免用聚合精度掩盖捷径。
