### 1. Averaging in gene perturbation benchmarks hides perturbation-strength variation: Consequences for model evaluation（77/100）
- 链接：https://www.biorxiv.org/content/10.64898/2026.10.20.760537v1
- 类别：评测 / 基准构造伪影；置信度：medium
- 分项：`{"question_shift": 23, "decision_or_experiment_shift": 15, "information_shift": 12, "evaluation_shift": 15, "evidence_strength": 8, "nontriviality": 4}`
- 新问题：扰动基准把同一扰动的所有细胞取平均，这一步丢掉了扰动强度信息——丢了多少，现有模型还保不保留可用于评估扰动强度的信息？
- 中文简介：把「每条扰动 = 全部细胞求平均」这一基准构造本身当作被审对象：用 X-Atlas/Orion CRISPRi 筛选中深度校正后的 guide 丰度作为细胞级扰动强度代理，检验同一名义扰动内部的转录响应如何变化。结果有三层。其一，强度越高响应可复现性越好，在 HCT116 与 HEK293T 中均存在，HCT116 更强——说明求平均会把「有多少细胞真的被敲低」这一层信息抹平。其二，HCT116 检索测试中观测响应仍保留扰动身份，而被评估的 STATE 与 Cell2Sentence 预测不能可靠恢复扰动身份。其三，也是最关键的负面结论：既然模型输出连扰动身份都不保，用现有模型去评估「扰动强度」这个维度本身就没有意义——基准缺口不只是缺指标，而是模型没有可用于该指标的信息。这是继上周 delta gap 之后，又一篇指出「主流扰动评测在测什么」的方法学工作。
- 证据与限制：bioRxiv v1 预印本，未经同行评审；全文未取到（仅摘要），guide 丰度作为扰动强度代理的效度、检索测试的具体设计与两种细胞系的细胞数/guide 数未核实；只评估了 STATE 与 Cell2Sentence 两个模型，不能推广到所有预测器；未验证。
- 与本项目：直接竞争
- 建议动作：在我们所有 Perturb-seq 基准里加入分层报告（按实测敲低强度分层），并停止在未保留强度信息的预测上评估强度相关指标。

### 2. How Much Can AI Virtual Cells Gain from Unified Perturbational Modeling? (UPM)（74/100）

- 类别：数据面 / 统一扰动建模；置信度：medium
- 分项：`{"question_shift": 20, "decision_or_experiment_shift": 15, "information_shift": 14, "evaluation_shift": 11, "evidence_strength": 11, "nontriviality": 3}`
- 新问题：把测到的基因集合、扰动类型、细胞环境都异构的 Perturb-seq 数据整合进单一模型，AIVC 到底能额外得到多少？
- 中文简介：把 AIVC 的核心瓶颈落在数据异构而非架构：不同 Perturb-seq 数据集的测量基因集、扰动类型、细胞环境都不同，现有预测器只在特定设定下开发。作者提出统一扰动建模（UPM）范式，在 VAE 型 AIVC 预测器中加入三个统一模块——基因通道对齐、共享扰动编码、基因表达与身份的联合嵌入——并逐一验证贡献。在此之上组装 1.1 亿细胞、>22,000 基因、4 种扰动类型、76 种细胞环境的数据集，用 71 个环境、8,970 万细胞训练 >10 亿参数的统一预测器。遗传扰动基准上 PES 与逐基因响应相关最高；在五个留出 Tahoe-100M 细胞系上四项指标全部优于 State，在 cytokine 基准上优于 Stack；组合扰动预测优于专门预测器；HSC 应用中复现肝星状细胞靶点敲低效应的下游任务准确率提升 40.0%。
- 证据与限制：bioRxiv v1 预印本，未经同行评审；全文未取到（仅摘要），三个统一模块的消融表、PES 计算口径、留出环境划分与训练/测试泄漏控制未核实；1 亿级训练与 10 亿参数的可复现性依赖其公开代码（未运行）；全部为回顾性基准提升，无前瞻实验闭环；「40% 下游任务提升」的具体任务定义未核实。
- 与本项目：直接竞争
- 建议动作：把 UPM 的异质性来源（基因集/扰动类型/环境）作为我们数据侧的固定对齐清单，并把它当本周最强的统一建模基线来对照。

- 中文简介：ImmunoTwin 用原代人类 CD4+ T 细胞的基因组规模 CRISPRi Perturb-seq（2,200 万细胞、4 名供体）导出细胞毒效应程序的调控图谱，并以三条独立证据校验：CRISPR 激活下方向反转（ρ=-0.53）、与独立分选筛选中 IFN-γ 产量的一致性（ρ=0.69）；巨噬细胞 Perturb-seq 中恢复 TLR4-NF-κB 作为 LPS 响应调控通路（通路级 P=0.0004），且转录效应与独立供体实测 TNF 蛋白一致（ρ=0.58）。更重要的负面结果是：两种细胞里，「通用扰动强度」这一指标恢复功能性筛选命中优于程序特异效应（ROC AUC 0.96 vs 0.73；0.87 vs 0.72）——提示很多「程序特异调控因子」可能只是敲低效率的代理。最后把「T 细胞耗竭标志与巨噬 M1 程序耦联」固定为假设，先在 7 个队列 90 例患者中观察到（r=0.43），再在 6 个队列 86 例中一次性检验。

### 4. Transferring CRISPRi knockdown responses to new cell lines requires screening part of each line（73/100）
- 链接：https://www.biorxiv.org/content/10.64898/2026.11.15.766815v1
- 类别：迁移 / 实验预算决策；置信度：medium
- 分项：`{"question_shift": 19, "decision_or_experiment_shift": 17, "information_shift": 12, "evaluation_shift": 12, "evidence_strength": 10, "nontriviality": 3}`
- 新问题：把敲低响应迁移到新细胞系，到底有多少是共享的、新细胞系必须自己贡献多少——能否用「需要筛多少比例的细胞系」把这件事量化成实验预算？
- 中文简介：把「跨细胞系迁移」从一个模糊的能力声明变成一个可预算的实验决策：用四个人类细胞系的必需基因 CRISPRi Perturb-seq，结合噪声上限与校准指标来问「一个响应里有哪部分是共享的，新细胞系必须贡献什么」。噪声校正后响应中位相关为 0.52，TP53 野生型细胞系之间最高。只筛选一个细胞系 30% 即可：线性模型与 CASTER 分别达到 0.84 与 0.80（1 表示技术重复），而直接迁移的均值只有 0.44；CASTER 只在 2.5% 筛选比例下领先（0.62 vs 0.47），完全不筛选时低于迁移均值。响应幅度主要随一般必需性变化，而非细胞系特异依赖。这给 AIVC 领域一个直接的决策结论：迁移模型很少打败简单均值，要大幅超过均值就必须在目标细胞系里实际筛一部分。
- 证据与限制：bioRxiv v1 预印本，未经同行评审；全文未取到（仅摘要），噪声上限的估计方式、四个细胞系的筛选规模与 CASTER 的集合建模细节未核实；结论限定于必需基因 CRISPRi 与四个细胞系；未验证。
- 与本项目：直接竞争
- 建议动作：把「目标系先筛 N% 再迁移」写进我们的实验设计默认选项，并把直接迁移均值作为任何迁移模型的硬基线。

- 类别：标注范式 / 分级响应推断；置信度：medium

- 新问题：细胞对外部输入的解码是有强弱之分的，能否在没有剂量分辨训练标签的情况下，从组合扰动筛选中同时推断输入的「身份」和「强度」？
- 中文简介：指出现有扰动-响应模型把暴露于同一输入的所有细胞当成一个离散类别，忽略了响应幅度的细胞间差异，而这一点对细胞命运工程至关重要。CIRCE 把每个扰动组合表示在二值组合空间里，用随汉明距离衰减的 Boltzmann 分布替代 one-hot 监督，从而在没有剂量分辨训练标签的条件下同时推断输入身份与强度。结果是保住了分类准确率，同时改善校准、并在单细胞层面解析出连续的通路活性；一个值得记录的推论是：中间分数主要反映细胞响应状态本身的模糊性，而非模型知识不足。在工程化组织与天然组织中都能恢复分级活性。
- 证据与限制：bioRxiv v1 预印本，未经同行评审；全文未取到（仅摘要），汉明距离衰减核的函数形式、校准指标定义与「中间分数=状态模糊」这一推论的证据链未核实；分级活性的真值来自何处未说明；未验证。
- 与本项目：可迁移方法
- 建议动作：把「离散扰动标签 → 强度/分级标签」作为我们数据标注的下一个改造方向，并留意中间分数不可直接当置信度。

### 6. ReliFlow: Reliability-Calibrated Residual Transport for Combinatorial Single-Cell Perturbation Prediction（66/100）
- 链接：https://arxiv.org/abs/2611.23999
- 类别：组合扰动 / 可靠性校准；置信度：medium
- 分项：`{"question_shift": 17, "decision_or_experiment_shift": 13, "information_shift": 12, "evaluation_shift": 12, "evidence_strength": 9, "nontriviality": 3}`
- 新问题：组合扰动预测里，「干预之间的交互」与「单扰动效应估计本身的误差」能否被显式分开，而不是都塞进一个残差场？
- 中文简介：把组合扰动预测拆成两个必须区分的东西：干预之间的相互作用，与单扰动效应估计的误差；后者在单扰动证据稀疏或被留出时更严重。ReliFlow 用条件 flow matching，仅用训练集交叉拟合估计单基因效应的可靠性，再用这些可靠性校准加性源分布，把速度场分解为「加性参照的已知修正」+「学习到的残差输运场」。Norman 遗传扰动上，MAE 从 0.142 降到 0.131（未见组合但单扰动已观测），从 0.198 降到 0.178（连构成单扰动也被留出）；ComboSciPlex 留出药物组合 MAE 0.191→0.176；非加性残差相关 0.574→0.638；分量消融确认可靠性加权的贡献。
- 证据与限制：arXiv v1 预印本，未经同行评审；全文未取到（仅摘要），交叉拟合的具体划分、MAE 的基因集与归一化、以及是否与强基线（如 GEARS/chemCPA 系列）全面比较未核实；提升幅度中等（约 7-10%），属方法改进而非范式改变；未验证。
- 与本项目：可迁移方法
- 建议动作：在组合扰动任务里把「单扰动可靠性」作为一等输入特征，并把留出单扰动的设定作为标准测试切分。
